app/ingestion/policy_parser.py
  - parse_policy_pdf(pdf_path, llm_client) → PolicyParseResult
  - Converts unstructured policy PDFs into validated PolicyRule objects
  - Preserves explicit rule IDs (e.g. POLICY-001); generates deterministic POLICY-9NN IDs when implicit
  - Surfaces ambiguous clauses in result.ambiguous_statements
  - Never fabricates rules or substitutes default fallback rules on failure

app/service.py
  - Top-level Application Service boundary: DealReviewService, DealReviewRequest, DealReviewResponse
  - Single functional API: service.run(request) → DealReviewResponse
  - Keeps UI presentation-only (UI calls DealReviewService; never invokes graph directly)
  - Enforces mandatory Deal PDF + Policy PDF requirement
  - Hard stops on policy parsing failure without fallback to bundled rules

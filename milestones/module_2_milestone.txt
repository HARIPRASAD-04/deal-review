3. KEY DESIGN DECISIONS
--------------------------------------------------------------------------------

1. EvidenceSnippet.clause → Optional[str]
   When no section/clause can be deterministically identified, clause=None is
   stored. This avoids invented labels like "Page 2 Block 5". Empty string ""
   still raises a validation error (min_length=1 still applies to non-None values).

2. source_pdf_path on WorkflowState (Optional[str])
   The caller explicitly provides the PDF path. The ingest_document node does
   NOT try to infer the path from document_id. This keeps the node stateless
   and the graph deterministic.

3. EvidenceRegistry: dict-backed, not a vector store
   Simple provenance layer — not RAG. Supports add, get, get_or_none, has,
   list_all, list_for_document, to_dict. Duplicate IDs rejected.

4. Deterministic sequential IDs (EV-001, EV-002, ...)
   Global counter incremented across pages in document order. Same unchanged
   PDF → same IDs → same ordering every time. Confirmed by 9 determinism tests
   including 5 consecutive runs.

5. Graceful failure in LangGraph node
   ingest_document() never raises an uncontrolled exception. On failure it
   emits DOCUMENT_INGESTION_FAILED audit event and records an error — the
   graph run continues without crashing.

6. Minimal text normalization
   Strip surrounding whitespace, collapse excessive blank lines. Preserve all
   financial symbols, percentages, qualifiers ("subject to", "not less than",
   "provided that", "except", "not exceeding", "at least").

5. KNOWN LIMITATIONS (Documented per spec)
--------------------------------------------------------------------------------
- The fixture deal_002.pdf uses standard ASCII hyphens (-) in heading titles so PyMuPDF
  extracts section headers cleanly without font-encoding issues.
- PyMuPDF does NOT perform OCR. Scanned/image-only pages produce no text.
- Complex multi-column layouts may produce text in unexpected order.
- Table content may not segment cleanly into paragraph-like units.
- Section detection is heuristic and will miss non-standard heading formats.
